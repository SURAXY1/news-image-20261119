A program that draws a newspaper front page summing up the world's news
of Thursday 19 November 2026, and writes it to `/output/entry.png`.

The front page leads with the Trump-Xi-Putin summit in Shenzhen and the
worldwide rollout of GTA VI, then covers the attack on the Kerch Bridge,
Voyager 1 reaching one light-day from Earth, the EU's 45bn euro loan plan
for Ukraine, and Cyclone Akvan bearing down on India's east coast — with
the day's other headlines running along the foot of the page.

## Run it

```sh
python3 main.py
```

The program needs only Python 3.13 and its standard library: a hand-rolled
rasterizer, a 5x7 bitmap font and a PNG encoder, all in one file. It reads
nothing, reaches no network, and writes the same bytes on every run.
